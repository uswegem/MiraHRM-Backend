# Security Policy

MiraHRMS is a fork of [Frappe HR](https://github.com/frappe/hrms), maintained separately.

To report a security issue in this fork, please open a private
[GitHub Security Advisory](https://github.com/uswegem/MiraHRM-Backend/security/advisories/new) on
this repository rather than a public issue.

Issues in the underlying Frappe Framework, ERPNext, or unmodified upstream Frappe HR code should also
be reported upstream, per [frappe.io/security](https://frappe.io/security), since a fix there benefits
this fork too.

We appreciate your efforts to responsibly disclose your findings and will respond as quickly as we can.
